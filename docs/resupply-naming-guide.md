# Resupply paperwork — how it is filed and named

*For all TechnoMed staff. 20 November 2026.*

## The short version

1. **Scan every resupply in the portal**: Scan → **Resupply**. Don't drag it into Dropbox by hand.
2. **Check the case it matched.** If the portal picked the wrong case, or none, use **Find the case**.
3. **Read the name under "Will be filed in the case folder as".** The portal works the name out for you. You can't type one, and you don't need to.
4. Tap **Record and file in the case folder**. It goes in that case's own folder, next to the usage.

From November 2026 everything is filed in the portal's folders only:
`ALL SURGEON USAGE / SPINE / {Surgeon} / {Month Year} / {case folder}`.
Please don't make folders in the old `SPINE Usage / … - SPINE` tree any more. It stays as the history up to October 2026.

## How the names work

These are the names the team has used in Dropbox since 2020. The portal now applies them for you.

| What the paper is | Name |
|---|---|
| Everything used has come back in one go | `Testa Signus resupply.pdf` |
| First of several, so some is still owed | `Testa partial Signus resupply.pdf` |
| A later one, with some still owed | `Testa partial Signus resupply 2.pdf`, then `… 3` |
| The one that finishes it | `Testa remaining Signus resupply.pdf` |

**Supplier words:** Signus · E4 · Device · **Boost** · KT · Globus · DTBV

## Boost is not Device

Device Technologies send Boost allograft and Device implants (Mariner, Dakota and so on) separately. Each has its own paper and its own name:

- Boost allograft → `Testa Boost resupply.pdf`
- Device implants → `Testa Device resupply.pdf` (or `partial` / `remaining`)

The portal decides which one it is from the lines on the paper and the usage they match. A Boost paper is never counted towards the Device implants (or the other way round), so a Boost resupply can no longer end up named "partial Device resupply".

If the **From** box shows the wrong supplier, change it. The portal checks it again against the paper and the usage. It still won't let a Boost paper be filed as Device.

## When the portal can't tell

- **No usage was scanned for the case:** it records the resupply but can't file it in a case folder. Tell the team leader so the usage can be scanned first.
- **Wrong case offered:** tap **Find the case** and search by surname, surgeon or folder name.
- **Not a resupply at all:** if it is really a usage form, the portal stops and offers **Read it as a usage**.
- **E4's reprinted chargeable form:** E4 send a reprint of the hospital's chargeable-items form back as their resupply. That *is* the E4 resupply: scan it under **Resupply** as normal and it is filed as `Testa E4 resupply.pdf`.

## Things that are still filed by hand (for now)

- **RHH Reform restock photos** (`Testa RHH Reform resupply.jpeg`): keep filing these as you do now.
- **KT one-off items** (e.g. `Testa KT crosslink resupply.pdf`): scan them as normal and the portal names them `Testa KT resupply.pdf`.

Questions or a wrong name: post in **Portal feedback**.
